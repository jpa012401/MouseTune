# Credits

## Mac Mouse Fix

MouseTune exists because of [Mac Mouse Fix](https://github.com/noah-nuebling/mac-mouse-fix) by **Noah Nuebling**.

Mac Mouse Fix showed what an ordinary mouse on a Mac can feel like. Its smooth scrolling, button remapping and click-and-drag gestures for Spaces and Mission Control were the reference for how MouseTune should behave. Studying it also showed which macOS techniques work in practice.

MouseTune is an independent, clean-room implementation. It contains no Mac Mouse Fix source code, and nothing in it was translated from Mac Mouse Fix. Behaviour and facts such as event fields, hotkey IDs and timings were re-derived and verified independently (see §13 of the [technical specification](docs/macos_mouse_utility_technical_specification.md)).
